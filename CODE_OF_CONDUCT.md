# Code of Conduct

We want this project to be a respectful, harassment-free space for everyone.

**Expected behavior**

- Be kind and constructive. Critique code and ideas, not people.
- Assume good intent and help newcomers.
- Respect different experience levels, backgrounds and opinions.

**Unacceptable behavior**

- Harassment, insults, discrimination or personal attacks.
- Publishing others' private information.
- Spam, trolling, or deliberately derailing discussions.

**Enforcement**

Maintainers may edit or remove comments, issues and contributions that do not follow this code, and may ban repeat offenders. To report a problem, contact the maintainers through the contact method listed in [SECURITY.md](SECURITY.md) or by opening a private report on GitHub.

This code applies in all project spaces and when someone represents the project in public.
